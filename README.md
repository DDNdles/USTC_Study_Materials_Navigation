# 中科大本科课程资料导航

这是一个给中科大本科生找学习资料的网站。输入课名或课号，就能看到这门课有哪些往年试题和解析、作业与小测、学习资料、教材与参考书，以及大作业和考核作品。准备复习时，可以按考试年份找题；想看看某个学科有哪些课程可参考，可以先按学科浏览，再筛出已有资料的课。

## 在线使用

公开网站尚未上线。项目目前保存在 [GitHub 私有仓库](https://github.com/TwinJades/UST_Study_Materials_Navigation)，仓库链接仅对有权限的用户可见。

## 怎么找资料

1. **找课程**：输入课名或官方课号，也可以按课程类别、学科、资料类型和收录状态缩小范围。同名或近似课程可以用课号区分。
2. **找试题**：选择「试题与解析」后按年份筛选。点进课程，可查看已知学年或年份、期中或期末、是否有解答等信息。
3. **看原始出处**：课程详情的简洁模式也保留已登记的原始页面，有独立文件直链时可另点「打开文件」。需要核对作者、其他来源或收录依据时，切换到详细模式。

目录覆盖 **2025 秋、2026 春、2026 夏、2026 秋**的 **1,184 门本科课程**，其中 **219 门**已收录 **1,383 条**资料。「暂未收录」表示目前索引里还没有该课程的资料。

## 让 Agent 帮你查

可以让 Agent 直接读取结构化的 `data/catalog.json`（上线后位于网站根地址下），按课号找课程、筛选资料并返回原始页面。无需解析网页；本地生成文件位置、字段和示例见[开发文档：Agent 与程序读取](docs/development.md#agent-与程序读取)。
